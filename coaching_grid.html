Who Coached Where — NCAA Wrestling Head Coaches, 1908–2026

Each column is one of the 22 winningest programs (ordered by all-time NCAA team points). Each row is a year. A cell is shaded in the school's official color; within a program, darker = more recent coach, lighter = older, so each coaching era reads as its own band. Grey = a documented gap with no reliably-sourced coach. Hover any cell for the coach and tenure.
Tip: scan down a column to see how often a program changed coaches — a few wide bands (Iowa, Penn State, Oklahoma State) mark long dynasties; many thin bands mark churn.
